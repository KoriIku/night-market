# 改写版提示词：餐车夜市 × 暖光 × 人间烟火

> 由「春季晴天 × 满开樱花 × 复古路面电车」参考提示词改写，用于本项目场景生成与美术对齐。
> 要点：45 度是**观察视角**，不是街道本身；夜市由**餐车**组成，不用店铺。

## 速查要点

- 形式：微缩模型 + 正方形底座 + 第三视角，可拖拽旋转缩放；场景内不含任何 UI。
- 视角：街道笔直，相机约 45 度斜俯视环绕（斜的是视角，不是街道）。
- 主体：一条直街 + 十台手推餐车（烤冷面、烤串、冰粉、卤味、柠檬茶、果切、套圈、炸串、臭豆腐、糖炒栗子）。
- 餐车：轮子、木台面、低矮雨棚、小便签招牌、纸灯笼、炉灶/铁板/汤锅/冰柜、碗碟食材、摊主剪影；低矮通透，不做墙面门帘，俯视不挡视线。
- 灯光：灯笼串 + 摊位灯泡 + 招牌灯箱 + 二楼窗光 + 地面暖色光池 + 少量霓虹，整条街要亮。
- 动效：蒸汽油花、灯笼微闪、价签轻摆、地面光斑、偶有自行车或剪影路人；主角是唯一走动的人。
- 游戏约束：点击或触屏走位、相机跟随可环绕缩放、靠近餐车唤出菜单。
- 气质：安静又热闹，人间烟火，温暖治愈，二次元日常番。

请制作一个「深夜餐车夜市 × 暖黄灯火 × 人间烟火」的微缩三维场景模型，它同时是一款网页轻量小游戏的可玩场景。

整体形式：以第三视角观察整个场景，像一块可以自由拖拽、旋转、缩放的微缩模型，摆在一块完整的正方形底座上。底座边缘做一圈细装饰线，四周是低矮的沿街楼房与楼顶细节（水箱、空调外机、招牌、天线），构图紧凑、层次清晰，有小巧、精致、可收藏的模型感。场景自身不带任何 UI 元素；菜单、猜价和小票属于游戏外层界面，不属于这个模型。

观察视角：街道本身是笔直的，沿底座中线铺开；相机以约 45 度的斜俯视角环绕观察，让街道在画面里自然形成斜向的透视。相机可以绕场景旋转、拉近拉远。

画面风格：三渲二卡通渲染，浓厚的二次元日常番氛围；材质干净，轮廓线明确，色彩柔和但有夜景霓虹的层次感；以暖黄灯光为主调，冷蓝夜色作背景衬托。

场景主体是一条笔直的夜市街道，两侧一共十台餐车：烤冷面、烤串、冰粉、卤味称重、柠檬茶、果切、套圈、炸串、臭豆腐、糖炒栗子。每一台餐车要像真正的手推餐车：带轮子的车体、木质台面、低矮的条纹雨棚、小小的招牌灯箱与手写价签、挂在车边的纸灯笼、炉灶或铁板或汤锅或冰柜、碗碟与食材道具、车边挂着塑料袋和抹布，摊主是站在车后的简单剪影。餐车朝街道摆放，车体低矮通透，不做立起的墙面、不做门帘，俯视时要能直接看到车上的食物与台面，视线不被遮挡。

车与车之间留出走道，街道上摆塑料凳、矮桌、货箱、垃圾桶；街角有自行车、自动贩卖机、盆栽与电线杆，电线从头顶穿过。

灯光是重点，整条街要被点亮：灯笼串横跨街道，餐车的灯泡与招牌灯箱发亮，二楼窗户透出暖光，地面上是一滩滩暖色光池，少量霓虹点缀。画面要亮，但仍然保留夜色与烟火气。

动效：铁板与汤锅持续冒蒸汽和油花；灯笼与灯串轻微闪烁；餐车上的布旗、价签随风轻摆；地面光斑缓慢移动；偶尔有一辆自行车或一位剪影路人经过。主角是这条街上唯一会走动的人，其余都是静态剪影，让场景既热闹又安静。

游戏需求：主角可以在街道上走动（点击或触屏走位），相机跟随主角并支持自由环绕与缩放；走近餐车时，餐车的价签与菜单可以被唤出。

气质：安静的夜晚、热闹的烟火、温暖治愈，像一幕被定格下来又轻轻流动的动画街景模型。
