# 参考与灵感记录

> 本项目实际使用的场景提示词（餐车夜市版 + 速查要点）见 `docs/prompt-night-market.md`。

## 参考场景提示词（樱花 × 电车 × 微缩街角）

原始要求的关键点，值得保留的思路：

- 第三视角观察整个场景，像一个可以自由拖拽、旋转、缩放的微缩三维模型；地面是一块完整的方形底座。
- 构图紧凑、层次清晰，整体呈现小巧、精致、可收藏的模型感。
- 三渲二风格：浓厚日式二次元动画氛围、材质干净、轮廓明确、色彩柔和明亮。
- 场景内容要充实：店铺内部陈列、站台细节、车厢座椅都可见；没有人物，但生活气息很浓。
- 基础动效：花瓣飘落、电车道过、光影摇曳、风铃轻摆、信号灯规律变化。

## 夜市化改造（本项目采用）

- 微缩底座 → 一整块夜市街区底座，四周是矮楼与小店，中间一条 45 度斜穿画面的巷子。
- 樱花与阳光 → 红灯笼、暖黄灯串、蒸汽、油花、暖色地面光池。
- 电车动效 → 蒸汽升腾、灯笼微闪、地面光斑；后续可加自行车与摊主招呼。
- 站台/老铺 → 摊位车、暖帘（noren）、纸灯笼、招牌、货箱、塑料凳、自行车、自动贩卖机。
- 无人但生活气 → 摊位上的食物、称、碗碟、锅、菜单牌都在，只有主角一个人走动。

## 参考物（气质）

- 日本动画里的夜市/祭典街景：暖帘、灯串、摊位灯箱、湿漉地面反光。
- 《人生一串》式的烟火气：油烟、铁板、炭火、塑料凳、老板的围裙。
- 微缩模型摄影：低机位斜俯视、浅景深、底座边缘可见。
